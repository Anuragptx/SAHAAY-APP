# 🚨 SAHAAY – Anonymous Local SOS Platform

**SAHAAY** is a privacy-focused emergency assistance platform designed to connect people in need with nearby helpers through anonymous, location-based SOS alerts.

Our mission is simple: Make emergency assistance faster, easier, and accessible to everyone.

### 🌟 Key Features

* 🆘 **Instant SOS Alerts** – Broadcast emergency alerts with a single tap.
* 📍 **Location Sharing** – Share your location to help nearby people find you.
* 🗺️ **Live Map** – View nearby emergency alerts on an interactive map.
* 💬 **Real-Time Chat** – Communicate with people responding to emergencies.
* 🔒 **Anonymous Access** – No registration required.
* ⏱️ **Auto-Expiry** – Temporary alerts and chat messages.
* 📱 **Responsive Design** – Works across different screen sizes.

### 🛠️ Tech Stack

* React.js
* TypeScript
* Vite
* Tailwind CSS
* Firebase Firestore
* Leaflet.js
* OpenStreetMap

### 🎯 Our Vision

SAHAAY aims to build a community where people can help each other during emergencies.

Because sometimes, a little help can make a big difference.

### 🚀 Getting Started

```bash
git clone YOUR_REPOSITORY_URL
cd Local-SOS-Broadcast
pnpm install
```

Start the development server:

```bash
pnpm --filter @workspace/alertify run dev
```
